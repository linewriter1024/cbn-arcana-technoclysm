# Arcana Technoclysm for Cataclysm: Bright Nights

Adds a technical aspect to the Arcana mod. A faction of arcanists developed magical technology just before the Cataclysm. Includes summonable vehicles, new locations, and new magical tools.

Depends on [Arcana](https://github.com/chaosvolt/cdda-arcana-mod), which is bundled with Bright Nights.
